# Локальний запуск пекарні

Потрібен Python 3.11+ (рекомендовано 3.12).

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
./start.sh --set-password
.venv/bin/python import_photos.py
./start.sh --port 8013
```

Вітрина: http://127.0.0.1:8013/ · Кабінет: http://127.0.0.1:8013/admin

Задайте власний пароль від 12 символів. Повторний `--set-password` змінює пароль і завершує сесії. Початкові ціни та залишки є прикладами. Перед справжніми замовленнями перевірте кожну пропозицію, склад, телефон і місце самовивозу.

## Перевірка основних сценаріїв

1. Відкрийте доступний десерт, запам’ятайте залишок, забронюйте одну штуку з тестовими контактами. Залишок зменшиться. Посилання на статус збережеться в цьому браузері.
2. Увійдіть у кабінет, відкрийте замовлення й змініть статус. Оновіть сторінку статусу покупця. Скасуйте бронювання: одиниця повернеться в залишок лише один раз.
3. Натисніть «Замовити схожий» у галереї або доступній пропозиції. Запит на новий торт не зменшує запас готових десертів і потребує погодження власницею.
4. У десерті задайте витрати за штуку. Нові бронювання автоматично враховують їх; старі залишаються без змін.
5. Встановіть узгоджену ціну й витрати замовлення, позначте «Виконано». Воно потрапить у фінанси за місяцем виконання. Додайте іншу витрату й перевірте орієнтовний прибуток.

## Дані

База і фото зберігаються в `data/`. Робіть резервну копію SQLite та завантажених фото; для активної бази користуйтеся SQLite backup API, а не копіюванням лише основного файлу без WAL. Не публікуйте `data/` або `.env`.

У фінансах: валовий прибуток = виручка − виготовлення; орієнтовний чистий прибуток = валовий прибуток − інші записані витрати. Це не бухгалтерська звітність.
